# Nebula

Nebula — это автономная система спектрального анализа документов. Проект представляет собой утилиту для извлечения текстовых сигналов из документов или изображений. Вся обработка происходит на вашем устройстве.

Система базируется на нейросетевом движке EasyOCR и поддерживает работу с кириллицей и латиницей.

## Возможности системы

- Приём визуальных данных форматов JPG, JPEG, PNG.
- Распознавание сигналов на русском и английском языках.
- Вывод извлечённых данных в виде структурированного потока.
- Автоматическое сохранение архива на локальный диск.
- Полная автономность: сигналы не передаются на удалённые серверы.

## Требования

- Python 3.9+ (бортовая ОС).
- pip (менеджер пакетов).

## Инициализация системы

**1. Загрузка координат проекта:**

cd <папка_проекта>
